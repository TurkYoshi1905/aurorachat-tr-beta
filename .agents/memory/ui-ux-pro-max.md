# UI/UX Pro Max Skill

## Nedir

`.agents/skills/ui-ux-pro-max/SKILL.md` konumunda kayıtlı, kapsamlı bir UI/UX tasarım rehberi.

## Ne Zaman Kullanılır

Her UI bileşeni oluşturulduğunda, sayfa tasarlandığında, renk/tipografi/stil seçimi yapıldığında bu skill okunmalı.

**Why:** Kullanıcı bu skili özellikle istedi ve her oturumda aktif olmasını istiyor.

## Kapsam

- 50+ stil (glassmorphism, minimalism, brutalism, neumorphism vb.)
- 161 renk paleti, 57 font eşleşmesi
- 10 öncelik kategorisi: Erişilebilirlik, Dokunmatik Etkileşim, Performans, Stil, Layout, Tipografi, Animasyon, Formlar, Navigasyon, Grafikler
- React, Next.js, Vue, Svelte, SwiftUI, React Native, Flutter, Tailwind, shadcn/ui, HTML/CSS desteği
- Teslim öncesi kontrol listesi (visual, interaction, dark/light mode, layout, accessibility)

## How to Apply

UI/UX işi başlamadan önce skill'i oku: `.agents/skills/ui-ux-pro-max/SKILL.md`
